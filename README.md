### Descripción del Repositorio

Repositorio de código fuente del sistema de movimiento basado en motores que permita controlar dos tipos de 
actuadores mediante un joystick e incluya un mecanismo de detección de anomalías que permita 
bloquear y detener el sistema cuando se detecte un movimiento brusco.
